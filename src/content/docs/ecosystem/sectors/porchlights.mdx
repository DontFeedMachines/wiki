`porchlights.xyz` is a shelf of plain, focused utilities built to answer one question: why does this app need ai? every tool does one practical job locally, with no account, no model call, and no telemetry.

## What's on It

1. **SHELF**, the directory of standalone utilities.
2. **CHECK**, **LIGHT LIST**, and **OTHER OPTIONS**, verification, catalog, and non-ai alternatives.
3. **PROOF HOUSE**, side-by-side demonstrations showing how plain deterministic code replaces model wrappers.
4. **DESKTOP**, desktop-packaged builds of the tools.

## How It's Built

astro, static output, with a quiet-start toggle (`START UP QUIETLY`) that disables motion on boot.
