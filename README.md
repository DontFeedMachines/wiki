# Don't Feed Machines // WIKI v1.0.1


the source for the DFM wiki at [wiki.dontfeedmachines.com](https://wiki.dontfeedmachines.com): documentation for counter-surveillance, personal opsec, defensive tooling for an AI world, and privacy hardware you can build. the wiki is an Astro + Starlight/Dockit site with a teletext skin.

this folder is the site. the pages are in `src/content/docs/`.

## Run It

```bash
cd /path/to/dfm-wiki
```

```bash
pnpm install
```

```bash
pnpm dev
```

the terminal prints the local address.

the theme imports `@dontfeedmachines/fieldkit`. pnpm only.

## Scripts

| command | what it does |
|---|---|
| `pnpm dev` or `pnpm start` | `astro dev` |
| `pnpm build` | builds to `dist/` |
| `pnpm preview` | serves `dist/` |
| `pnpm check` | `astro check`, types and content |

## Offline

run `pnpm build` and serve `dist/` with any static file server. Pagefind search is built in, so search works without a connection. links to other DFM sites go online.

## Layout

```
astro.config.mjs        wires the json config into Starlight
public/                 static files
src/
  assets/               images and the logo
  components/           Starlight overrides, DocKit components, DFM components
  config/               config.json, sidebar.json, menu.en.json, social.json, theme.json, locals.json
  content/
    docs/               every page: ecosystem, general, guides, tools
    i18n/               ui strings
    sections/           reusable page blocks
  plugins/              remark-starlight-cards.mjs
  styles/               global.css, teletext.css, navigation.css and friends
  tailwind-plugin/      theme and grid plugins
```

the sidebar order comes from `src/config/sidebar.json`. a page named there sits above the autogenerated entries, and everything unnamed falls in after it sorted by filename.

## Contributing

1. **issues and fixes for the site code are welcome.** layout bugs, broken components, accessibility problems, build errors.
2. **the content is not open to pull requests.** the wiki pages are written and controlled by one person.
3. **want to write a guide?** guides and articles based on the wiki or any other part of the ecosystem are welcome at [learn.dontfeedmachines.com](https://learn.dontfeedmachines.com).
4. **the source is open to inspect, run and build on.**
